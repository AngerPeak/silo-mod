# Укрытие-17 (Silo) — мод для Minecraft 1.20.1 Forge

Новый тип мира **«Укрытие»** в окне создания мира: вы живёте внутри подземной башни на 48 уровней,
расследуете смерть главного инженера, чините воздушные насосы и решаете — остаться или выйти наружу.

## Как получить .jar (без установки чего-либо)

1. Создайте на GitHub пустой репозиторий.
2. Загрузите в него **всё содержимое этой папки** (включая скрытую `.github`).
3. Откройте вкладку **Actions** → workflow **Build mod** → дождитесь зелёной галочки (5–10 минут).
4. Внутри запуска, раздел **Artifacts** → `silo-mod-jar` → скачайте архив, внутри `silo-1.0.0.jar`.
5. Положите jar в `.minecraft/mods` (нужен Forge 1.20.1, версия 47.x).

Если сборка упала красным — откройте лог шага **Build** и пришлите ошибку, я её исправлю.

## Как играть

* Создать мир → *Тип мира* → **Укрытие**.
* Вы появитесь в каюте на 20 уровне, в инвентаре — **Журнал следователя** (ПКМ).
* Лестница идёт спиралью в центре; выход на этаж — в секторе сразу за решёткой.
* Терминалы (у лестницы на каждом уровне), ящики снабжения, улики (жёлтые), насосы (оранжевые), шлюз (уровень 1).

## Команды

`/silo journal` · `/silo accuse <0-3>` · `/silo choose stay|leave` · `/silo handin <iron|farm|medic|rats>`
Для тестов (оп): `/silo debug level <1-48>`, `/silo debug stage <1-7>`, `/silo debug culprit <0-3>`.

Мод создан по мотивам идеи сериала/книг «Silo»; сюжет, персонажи и тексты — оригинальные.
